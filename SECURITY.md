# Security Policy

## Experimental Software Notice

This repository contains experimental research software developed primarily via LLMs to evaluate automated AI gameplay automation and multimodal vision reasoning. It is not intended for production or mission-critical use.

## Reporting Security Issues

If you discover a potential vulnerability or security concern:
- Please report it through GitHub's Private Vulnerability Reporting feature (under the repository's **Security** tab).
- Alternatively, open an issue with the `security` label.
- Please **do not** submit sensitive personal data, active credentials, API keys, or private game account information in public issue descriptions.
